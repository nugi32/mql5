# MQL5 Code Collection

## Overview

This repository contains a collection of **MQL5 (MetaQuotes Language 5)** codes developed for algorithmic trading on the MetaTrader 5 platform.

Unlike a single-project repository, this repo includes **multiple Expert Advisors (EAs), indicators, and utilities**, each designed for different trading strategies, experiments, or learning purposes.

## Features

* Multiple trading strategies (trend-following, scalping, etc.)
* Custom indicators for technical analysis
* Modular and reusable code components
* Experimental and learning-focused implementations

## Usage

1. Clone or download this repository
2. Copy the files into your MetaTrader 5 directory:

   ```
   Experts/
   ```
3. Open MetaEditor and compile the desired files
4. Run them in MetaTrader 5 (Demo account recommended)
